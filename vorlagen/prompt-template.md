# Vorlage: Strukturierte Prompts & Agenten-Briefings

## 1. Prompt-Vorlage für Gemini (Chat / Einzelaufgabe)

```markdown
**Rolle:** Du bist [z. B. ein erfahrener technischer Redakteur / Projektmanager].
**Kontext:** [Hintergrund, Zielgruppe, vorhandene Informationen].
**Aufgabe:** [Was genau soll erstellt, analysiert oder verbessert werden?]
**Format:** [z. B. Markdown-Tabelle, Checkliste, max. 200 Wörter, JSON].
**Einschränkungen:** [Was soll vermieden werden? Welche Annahmen dürfen nicht getroffen werden?]
```

---

## 2. Briefing-Vorlage für Antigravity (Agentische Aufgabe)

```markdown
**Ziel:** [Welches konkrete Ergebnis soll am Ende vorliegen?]
**Kontext / Dateien:** [Relevante Dateien, Ordner oder Rahmenbedingungen]
**Akzeptanzkriterien:**
- [ ] Kriterium 1 (z. B. Dokument ist für Einsteiger verständlich)
- [ ] Kriterium 2 (z. B. Build / Tests laufen ohne Fehler durch)
- [ ] Kriterium 3 (z. B. Änderungen sind sauber dokumentiert)

**Vorgehen:**
- Erstelle zuerst einen kurzen Plan, falls offene Fragen bestehen.
- Halte Änderungen klein und nachvollziehbar.
```
