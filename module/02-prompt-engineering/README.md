# Modul 2: Prompt Engineering & Strukturierte Zusammenarbeit

- **Zeitbedarf:** ca. 3 Std. (Woche 2)
- **Vorlage:** [`vorlagen/prompt-template.md`](../../vorlagen/prompt-template.md)

## Lernziele
- Klare, reproduzierbare Prompts mit Rolle, Kontext, Ziel, Format und Grenzen schreiben.
- Fortgeschrittene Techniken (Few-Shot, Zerlegung, Review-Prompts) gezielt anwenden.
- Ergebnisse in direkt weiterverwendbaren Formaten (Markdown, Tabellen, JSON, Mermaid) anfordern.

## Themen
1. **Anatomie eines guten Prompts** – Rolle, Kontext, Aufgabe, Ausgabeformat, Einschränkungen.
2. **Iterative Zusammenarbeit** – Erst Entwurf, dann gezielte Kritik, dann Verfeinerung.
3. **Qualität sichern** – Die KI als kritischen Reviewer einsetzen („Finde Lücken und Annahmen“).

## Übungen
- **Basis-Übung:** 5 wiederverwendbare Prompt-Vorlagen für den eigenen Alltag erstellen (z. B. Meeting-Protokoll, E-Mail-Entwurf, Anforderungsklärung, Text-Review).
- **Technischer Ausblick:** Prompt-Vorlagen in Git versionieren und anhand von 2–3 festen Testbeispielen vergleichen.

## Checkliste
- [ ] Eigene Prompt-Sammlung mit mindestens 5 Vorlagen angelegt
- [ ] Mindestens eine komplexe Aufgabe iterativ in 3 Schritten verfeinert
- [ ] Strukturierte Ausgabe (Tabelle oder Diagramm) erzeugt
