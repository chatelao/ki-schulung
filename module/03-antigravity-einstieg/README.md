# Modul 3: Einstieg in Agentisches Arbeiten mit Antigravity

- **Zeitbedarf:** ca. 3–4 Std. (Woche 3)
- **Vorlage:** [`vorlagen/prompt-template.md`](../../vorlagen/prompt-template.md)

## Lernziele
- Den Unterschied zwischen Chatbot und KI-Agent praktisch verstehen.
- Aufgaben mit klaren Zielen und Akzeptanzkriterien an Antigravity delegieren.
- Ergebnisse über Diffs, Artefakte und Reviews souverän steuern (*Human-in-the-Loop*).

## Themen
1. **Chatbot vs. KI-Agent** – Planen, Dateien lesen/bearbeiten, Befehle ausführen, Fehler selbst prüfen.
2. **Antigravity-Arbeitsumgebung** – Workspaces, GitHub-Repositories, Artefakte, Terminal.
3. **Effektives Briefing** – Ziele & Akzeptanzkriterien statt kleinteiligem Mikromanagement.
4. **Human-in-the-Loop** – Änderungen prüfen, gezielt nachsteuern, Risiken erkennen.

## Übungen
- **Basis-Übung:** Antigravity beauftragen, eine strukturierte Projekt- oder Wissensseite im eigenen Repository zu erstellen und per Feedback-Schleife zu verbessern.
- **Technischer Ausblick:** Einen Feature-Branch anlegen, Änderungen als Pull Request prüfen und sauber zusammenführen.

## Checkliste
- [ ] Mindestens eine Datei-Aufgabe erfolgreich an Antigravity delegiert
- [ ] Änderungen vor der Übernahme kritisch geprüft (Diff / Review)
- [ ] Briefing-Vorlage auf eine eigene Aufgabe angewendet
